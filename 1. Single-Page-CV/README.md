# Adeyemi Daniel CV

A simple static personal resume and portfolio webpage for Adeyemi Daniel, a junior frontend developer.



## Overview

This project presents a concise online CV highlighting:

- Personal information and contact details
- Core technical skills
- Education background
- Work experience
- Portfolio and online links

The page is built as a static HTML document with no framework or package installation required.

## Notes

- No build step is required.
- No dependencies are installed.
- The page is suitable for a personal CV, portfolio landing page, or a starting point for a more advanced resume website.
